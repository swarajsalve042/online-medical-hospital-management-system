# Security policy

This is a portfolio learning project. Do not use it with real patient or payment data.

If you identify a security issue in this demo, do not publish real credentials or personal data in an issue. Contact the repository maintainer privately.

Before any real deployment, obtain a qualified security and privacy review. Required work includes role/record-level authorization, audit trails, secure secret management, TLS, backups and recovery tests, retention controls, dependency review, and compliance assessment for the applicable jurisdiction.
